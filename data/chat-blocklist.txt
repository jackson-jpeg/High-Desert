# High Desert phone lines — the project blocklist.
#
# Loaded by highdesert-live on start, on `systemctl reload highdesert-live`
# (SIGHUP), and within a few seconds of the installed file changing. To extend
# it: edit this file, commit, then `bash scripts/deploy-live.sh --blocklist`
# (copies it into /opt/highdesert-live and reloads; no restart, no dropped
# streams).
#
# This list is ON TOP of the `obscenity` library's English dataset, which
# already refuses slurs and sexual terms and masks mild profanity. Every term
# here is matched the same way a message is: case, accents, leetspeak (k1ll),
# lookalike letters (Cyrillic/Greek/fullwidth), repeated letters, and spacing
# or punctuation tricks ("k i l l", "k.i.l.l") are all seen through.
#
# Syntax (docs/live-chat.md, "Extending the blocklist"):
#   term             refuse a message containing this whole word or phrase
#   *term            ...also as the end of a longer word
#   term*            ...also as the start of a longer word
#   *term*           ...anywhere, even inside other words (mind Scunthorpe)
#   mask: term       replace it with asterisks instead of refusing
#   allow: term      never flag this word — fixes a false positive
#   b64:BASE64       a term you would rather not have readable here, base64-
#                    encoded (echo -n 'term' | base64). Combines: "mask: b64:..."
#
# Refused messages get a neutral "That can't go on the air." — the word that
# matched is never echoed back.
